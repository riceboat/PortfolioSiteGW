Human Activity Monitoring via Embedded Wi-Fi Network

Designed and engineered an embedded spatial sensing system utilizing Wi-Fi Channel State Information (CSI) to detect physical human movement within a target environment. Programmed custom embedded software routines in C and Python for signal data capture, noise reduction, and movement analysis. Developed a dynamic backend interface (PHP) to process ambient RF telemetry and visualize passive activity tracking in real time. Conducted extensive academic research and hardware parameter tuning to optimize detection accuracy.
